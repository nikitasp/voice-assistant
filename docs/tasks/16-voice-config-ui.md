# 16 — Voice configuration UI (bonus)

**Requirements:** VX-2, VX-4, AP-9, AP-10, AP-11, AP-12
**Depends on:** 12, 15

## Goal

Staff can preview and select the concierge voice.

## Scope

- Voice page with one card per voice: name and description.
- "Preview" button that plays the sample.
- "Select" action that sets the voice as active.
- Clear indicator of the currently active voice.

## Acceptance criteria

- [ ] All four voices are listed with descriptions (AP-9).
- [ ] Admin can select the active voice (AP-10, VX-2).
- [ ] Preview plays a sample for each voice (AP-11, VX-4).
- [ ] The active voice is visibly marked (AP-12).
